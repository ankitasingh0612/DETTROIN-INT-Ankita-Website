## 🛠️ Technologies Used

- **Frontend Core**: React.js (Single Page Application via Vite)
- **Styling**: Modern Custom CSS (Premium editorial layout, glassmorphism, responsive grid)
- **Icons**: Lucide React
- **Typography**: Playfair Display (Serif) & Outfit (Sans-serif)
- **Deployment**: Vercel (Auto-deploy from GitHub)

---

## ✨ Key Features & Improvements

1. **Premium Brand Design**: Deep Maroon `#7A1C2E`, Warm Beige `#F9F6F0`, Accent Gold `#C5A880` — luxury heritage editorial look
2. **Sticky Glassmorphic Navbar**: Auto color-shift on scroll with mobile hamburger drawer
3. **Dark / Light Mode Toggle**: Full theme switching across all pages
4. **Interactive Campus Gallery**: Filterable photo grid (Infrastructure, Academics, Sports, Campus Life)
5. **Testimonials Carousel**: Auto-sliding with star ratings and navigation arrows
6. **Event Countdown Timer**: Live countdown to next school event
7. **Admissions FAQ Accordion**: Expandable Q&A section with animated toggles
8. **Dynamic Fee Estimator**: Real-time fee calculator based on class and extras
9. **Secure Portal Login System**: Role-based dashboards for Teacher, Student, and Parent with credential form
   - **Faculty ERP**: Lesson plan tracker, task queue, staff circulars
   - **Staff Mail**: Mock Outlook inbox with clickable email reader
   - **Google Hub**: Shared G-Drive classroom folders
   - **Student ERP**: Attendance tracker, grade cards, announcements
   - **G-Classroom**: Digital classroom workspace
   - **Parent Portal**: Fee invoice tracker with payment simulation
   - **Fee Desk**: Full itemized fee breakdown with payment button
10. **Virtual Campus Tour**: 4-zone photo tour with real images (Sports, Labs, Pool, Classrooms)
11. **Floating Helpdesk Chatbot**: Smart Q&A bot for Admissions, Timings, Sports
12. **Academic Planner Calendar**: Monthly grid with highlighted event days
13. **Toast Notifications**: Animated success alerts on form submissions
14. **Mobile-First Responsive**: Pixel-perfect on all screen sizes

## ⚙️ Local Development Setup

```bash
# 1. Clone the repository
git clone https://github.com/ankitasingh0612/DETTROIN-INT-Ankita-Website.git

# 2. Enter project directory
cd DETTROIN-INT-Ankita-Website

# 3. Install dependencies
npm install

# 4. Run development server
npm run dev

# 5. Create production build
npm run build
```
