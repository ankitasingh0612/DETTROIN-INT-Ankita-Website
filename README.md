## 🛠️ Technologies Used

- **Frontend Core**: React.js (Single Page Application via Vite)
- **Styling**: Modern Custom CSS (Premium editorial layout, glassmorphism, responsive grid framework)
- **Icons**: Lucide React
- **Typography**: Playfair Display (Serif header font) & Outfit (Modern sans-serif body font)

---

## ✨ Key Improvements Made

1. **Brand Aesthetic Alignment**: Applied the official Vasant Valley School colors (Deep Maroon `#7A1C2E` and Warm Beige `#F9F6F0` with Accent Gold `#C5A880`) to provide a luxury, heritage editorial experience.
2. **UX Enhancements**: Created a sticky glassmorphic navigation header with automatic color shifting on scroll, giving a clean modern interface.
3. **Interactive Tabs & States**: Added real-time reactive tabs on the Academics page, letting parents inspect Junior, Middle, and Senior divisions with clean animated layouts.
4. **Responsive Form Handlers**: Fully functional mock forms for admissions query and contact inquiries with clear success panels upon submission.
5. **Notice Board Section**: Designed a beautiful dedicated announcements grid mimicking real-time notices on the homepage.
6. **Mobile First Architecture**: Zero dependencies grid layouts, ensuring pixel-perfect views on phones, tablets, and wide screens.

## ⚙️ Development Command Setup

To preview and run the project locally:

```bash

cd DETTROIN-INT-VasantValley-Website

# 2. Install dependencies
npm install

# 3. Run development server locally
npm run dev

# 4. Create production build
npm run build
```
